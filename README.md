# TypeScript Çalışma Projesi

TypeScript öğrenirken temel ve orta düzey TypeScript yapılarını pratik olarak görmek amacıyla oluşturulmuş React + TypeScript projesidir. Çalışmalar `src/App.tsx` dosyasında bulunmaktadır.


## 📌 İçerik

* Temel Tipler: `string`, `number`, `boolean`, `array`, `any`, `undefined`, `null`, `unknown`
* Union Types
* Literal Types
* `type` / `interface`
* Optional Properties
* Tuple Types
* Fonksiyon ve dönüş tipleri
* Object parametreleri
* Rest Parameters
* Interface `extends`
* Utility Types: `Partial`, `Required`, `Readonly`, `Pick`, `Omit`
* Generic Types
* `keyof` / `typeof`
* Mapped Types


## 🛠️ Teknolojiler

React · TypeScript · Vite · HTML · CSS · JavaScript


## 🚀 Kurulum

```bash
npm create vite@latest typescript_project_name -- --template react-ts
cd typescript_project_name
npm install
```


## ▶️ Çalıştırma

```bash
npm run dev
```

Terminalde verilen localhost adresini tarayıcıda açın.

Production build:

```bash
npm run build
```

Build'i lokal olarak görüntüleme:

```bash
npm run preview
```

## 📂 Proje Yapısı

```text
typescript-project/
├── public/
├── src/
│   ├── assets/
│   ├── App.tsx
│   ├── index.css
│   └── main.tsx
├── index.html
├── package.json
├── tsconfig.json
├── tsconfig.app.json
├── tsconfig.node.json
└── vite.config.ts
```

`App.tsx` → TypeScript çalışmalarının bulunduğu ana dosya.
`main.tsx` → React uygulamasının başlangıç noktası.
`index.css` → Genel CSS dosyası.
`package.json` → Proje bağımlılıkları ve script'leri.
`tsconfig.json` → TypeScript yapılandırması.


## 📝 Not

Bu repository, TypeScript yapılarını öğrenmek ve test etmek amacıyla hazırlanmıştır. İlerleyen aşamalarda daha gerçekçi React uygulamaları ve component örnekleri eklenebilir.
